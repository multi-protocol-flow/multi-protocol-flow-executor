# TLS Verification Tests

This directory contains a complete test suite for HTTP node TLS functionality.

## Prerequisites

1. **Generate test certificates** (one-time):

```powershell
cd D:\projects\multi-protocol-flow-executor\tests\certs
.\generate-certs.ps1
# Or manually run openssl commands (see below)
```

2. **Build mpe CLI**:

```powershell
cd src-tauri
cargo build --bin mpe
```

3. **Node.js** >= 18 (for test server)

## Quick Start

```powershell
# Run all tests with one command (auto start/stop server)
node tests/run-tls-tests.mjs
```

## Manual Testing

### 1. Start Test Server

```powershell
# Standard mode (server certificate only)
node tests/https-test-server.mjs

# mTLS mode (requires client certificate)
node tests/https-test-server.mjs --mtls
```

### 2. Execute Test Flow

Certificate paths in flow files are relative to the project root. Execute from the project root directory:

```powershell
# Execute directly from project root (no path patching needed)
cd D:\projects\multi-protocol-flow-executor
src-tauri\target\debug\mpe.exe run -f tests\cli\tls_01_basic_ca_verify.json
```

## Test Cases

| File | Description | Server Mode | Expected Result |
|------|-------------|-------------|-----------------|
| `tls_01_basic_ca_verify.json` | Correct CA certificate | standard | ✅ 200 success |
| `tls_02_skip_verify.json` | Skip certificate verification | standard | ✅ 200 success |
| `tls_03_mtls_auth.json` | mTLS mutual authentication | mtls | ✅ 200 success |
| `tls_04_ca_missing.json` | Missing CA certificate (expected failure) | standard | ❌ unknown issuer |
| `tls_05_wrong_ca.json` | Wrong CA certificate (expected failure) | standard | ❌ unable to get local issuer |

## Certificate Files

Certificates in `tests/certs/` (generated by `generate-certs.ps1`):

| File | Description |
|------|-------------|
| `ca.key` / `ca.pem` | CA root certificate (correct) |
| `ca-wrong.key` / `ca-wrong.pem` | Wrong CA (for negative testing) |
| `server.key` / `server.pem` | Server certificate (SAN: localhost, 127.0.0.1) |
| `client.key` / `client.pem` | Client certificate (for mTLS) |
