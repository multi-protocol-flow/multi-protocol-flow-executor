# 流程调试器 UI 设计

**创建时间**: 2026-03-06
**关联文档**: debug-mode.md

## 一、整体布局

### 1.1 正常模式

- 顶部工具栏：执行按钮 + 调试按钮（禁用状态）
- 左侧：节点库
- 中间：流程画布
- 右侧：配置面板

### 1.2 设置断点后

- 调试按钮启用（绿色图标）
- 有断点的节点显示红色圆点标记

### 1.3 调试模式（暂停中）

- 顶部：调试工具栏（蓝色背景）
- 左侧：节点库（禁用）
- 中间：流程画布（当前节点蓝色边框高亮）
- 右侧：调试面板（蓝色边框）

## 二、核心组件

### 2.1 顶部工具栏

#### 正常模式
- 位置：画布顶部居中，悬浮
- 背景：白色半透明，毛玻璃效果
- 按钮：
  - 执行按钮：红色播放图标
  - 调试按钮：灰色虫子图标（无断点时禁用，有断点时绿色可点击）

#### 调试模式
- 位置：画布顶部居中，悬浮
- 背景：蓝色半透明（#3B82F6）
- 按钮：
  - 继续按钮：绿色播放图标
  - 单步按钮：蓝色下一步图标
  - 跳过按钮：橙色跳过图标
  - 执行到底：紫色快进图标
  - 结束调试：红色停止图标
- 按钮状态：
  - 暂停时：所有按钮可点击
  - 执行中：所有按钮禁用，显示加载动画

### 2.2 节点断点标记

- 位置：节点右上角
- 视觉状态：
  - 无断点：灰色空心圆（悬停变红色）
  - 有断点：红色实心圆
  - 当前暂停：红色实心圆 + 节点蓝色边框高亮
  - 已执行：绿色勾号 ✓

### 2.3 调试面板

- 位置：画布右侧，替代配置面板
- 背景：白色
- 边框：蓝色（#3B82F6），2px
- 宽度：320px

#### 面板内容
1. **当前节点区域**
   - 节点名称
   - 状态：暂停中（执行前）

2. **上下文变量区域**
   - 变量列表（每行一个）
   - 简单类型：直接显示
   - 复杂类型：折叠显示，点击展开
   - 操作按钮：
     - 编辑按钮（✏️）：打开编辑对话框
     - 复制按钮（📋）：复制到剪贴板

3. **执行堆栈区域**
   - 已执行节点：绿色勾号 ✓
   - 当前暂停节点：暂停图标 ⏸
   - 可展开查看输入/输出数据
   - 点击节点名称：画布跳转到该节点

4. **节点输出预览区域**
   - 节点执行前：显示 "(等待执行)"
   - 节点执行后：显示 JSON 格式输出
   - 复制按钮：复制输出到剪贴板

### 2.4 跳过节点对话框

#### 条件节点对话框
- 标题：跳过条件节点
- 内容：
  - 节点名称
  - 分支选择（单选）：
    - true → 下一个节点名称
    - false → 下一个节点名称
- 按钮：取消、确认跳过

#### HTTP/WebSocket 节点对话框
- 标题：跳过HTTP节点
- 内容：
  - 节点名称
  - 分支选择（默认 out）
  - 模拟输出（可选）：JSON 编辑器（语法高亮）
  - 提示：模拟输出将注入到变量池
- 按钮：取消、确认跳过

### 2.5 变量编辑对话框

- 标题：编辑变量
- 内容：
  - 变量名（只读）
  - 变量值（可编辑）
    - 简单类型：单行文本框
    - 复杂类型：多行 JSON 编辑器
  - 提示：修改仅当前调试会话生效
- 按钮：取消、保存

## 三、交互流程

### 3.1 开始调试

1. 用户在节点上设置断点
2. Debug 按钮启用（绿色）
3. 点击 Debug 按钮
4. 顶部工具栏切换为调试工具栏（蓝色背景）
5. 右侧面板切换为调试面板
6. 开始执行，到达第一个断点
7. 节点高亮（蓝色边框）
8. 调试面板显示当前节点和变量
9. 工具栏按钮启用，等待用户操作

### 3.2 继续执行

1. 点击"继续"按钮
2. 按钮禁用，显示加载动画
3. 执行当前节点
4. 更新执行堆栈（添加当前节点）
5. 自动执行后续节点（无断点的）
6. 到达下一个断点 OR 流程结束
7. 如果是断点：暂停，节点高亮，更新调试面板，按钮启用
8. 如果是结束：调试会话结束，恢复正常工具栏，显示"调试完成"提示

### 3.3 单步执行

1. 点击"单步"按钮
2. 执行当前节点
3. 更新执行堆栈
4. 在下一个节点暂停（不管有没有断点）
5. 节点高亮
6. 更新调试面板

### 3.4 跳过节点

1. 点击"跳过"按钮
2. 弹出跳过节点对话框
3. 用户选择分支（+ 可选模拟输出）
4. 点击"确认跳过"
5. 不执行当前节点
6. 如果有模拟输出，注入到变量池
7. 在下一个节点暂停
8. 节点高亮
9. 更新调试面板

### 3.5 执行到底

1. 点击"执行到底"按钮
2. 所有按钮禁用
3. 执行当前节点
4. 继续执行后续所有节点（忽略断点）
5. 流程结束
6. 调试会话结束
7. 恢复正常工具栏

### 3.6 结束调试

1. 点击"结束调试"按钮
2. 弹出确认对话框："确定要结束调试吗？已执行的节点数据将丢失。"
3. 用户确认
4. 终止调试会话
5. 不生成执行报告
6. 恢复正常工具栏
7. 调试面板关闭，恢复配置面板

## 四、视觉效果

### 4.1 颜色方案

| 元素 | 颜色 | 说明 |
|------|------|------|
| 调试工具栏背景 | #3B82F6 | 蓝色，区别于正常模式 |
| 断点标记 | #EF4444 | 红色，醒目的断点标识 |
| 当前暂停节点边框 | #3B82F6 | 蓝色，高亮当前节点 |
| 已执行节点勾号 | #10B981 | 绿色，表示已完成 |
| 继续按钮 | #10B981 | 绿色，执行操作 |
| 单步按钮 | #3B82F6 | 蓝色，下一步操作 |
| 跳过按钮 | #F59E0B | 橙色，警告操作 |
| 结束调试按钮 | #EF4444 | 红色，终止操作 |
| 执行到底按钮 | #8B5CF6 | 紫色，快速执行 |

### 4.2 动画效果

| 场景 | 动画 |
|------|------|
| 设置断点 | 圆点放大 + 颜色变化（200ms） |
| 到达断点 | 节点边框闪烁（2次，每次 300ms） |
| 执行中 | 按钮显示旋转加载图标 |
| 执行堆栈添加 | 新条目滑入动画（150ms） |
| 变量更新 | 高亮闪烁（1次，200ms） |

## 八、状态反馈

### 8.1 加载状态

- 按钮执行中：显示旋转加载图标（Loader2）
- 变量加载：骨架屏（Skeleton）
- 堆栈加载：骨架屏（Skeleton）

### 8.2 错误状态

- 节点执行失败：红色边框 + 错误图标
- 错误提示：Toast 通知（右上角）
- 调试面板：显示错误信息

### 8.3 成功状态

- 调试完成：Toast 通知（右上角，绿色）
- 流程执行完成：显示完成提示

## 十、可访问性

### 10.1 语义化

- 工具栏：`<nav>` 标签 + `aria-label="调试工具栏"`
- 按钮：`aria-label` 描述按钮功能
- 对话框：`role="dialog"` + `aria-modal="true"`
- 断点标记：`aria-label="设置断点"`

### 10.2 状态通知

- 到达断点：`aria-live="polite"` 通知
- 执行完成：`aria-live="polite"` 通知
- 错误发生：`aria-live="assertive"` 通知

## 十一、设计注意事项

1. **视觉层次**：调试模式使用蓝色主题，明确区分正常模式
2. **操作反馈**：所有操作都有即时的视觉反馈
3. **状态清晰**：当前状态（暂停/执行中/结束）一目了然
4. **防误操作**：关键操作（结束调试）需要二次确认
5. **信息密度**：调试面板信息密度适中，不拥挤
6. **响应速度**：操作响应时间 < 100ms
7. **动画克制**：动画简洁，不影响性能
